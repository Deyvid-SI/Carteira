# Catálogo de especificações

Cada capacidade possui a mesma organização documental:

```text
capacidade/
├── spec.md
├── proposta/
│   └── proposal.md
├── design/
│   └── design.md
└── tasks/
    └── tasks.md
```

- `spec.md`: requisitos e cenários verificáveis no formato OpenSpec.
- `proposta/proposal.md`: problema, mudança, escopo, impacto e critério de conclusão.
- `design/design.md`: arquitetura, dados, regras, segurança, falhas e estratégia de testes.
- `tasks/tasks.md`: checklist rastreável da implementação.

Capacidades documentadas:

- `acoes`
- `api-openapi`
- `autenticacao`
- `corretoras`
- `dashboard`
- `infraestrutura`
- `isolamento-usuario`
- `negociacoes`
- `portal`
